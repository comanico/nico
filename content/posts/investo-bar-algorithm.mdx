# Introduction

In order to help people understand how a financial market works, best to implement it in an activity of everyday life.
Being in Romania, where people love to get together on a daily basis, bringing the financial market to a social gathering seems to be the answer.
Now we must understand how to create a market that reacts to the supply and demand from the bar.

# Algorithm

## Algorithm Variables

First we establish our base prices and cost of bottles the exchange paid for. Also we also want to set risk triggers in case a product is being more frequented than another, to avoid high prices.
In the stock market, prices change constantly by second, due to high transaction numbers, making prices change frequently. But because this is a bar and purchasing frequency is not as high as the stock market, a price change every 15 minute is the more relaxing option, for the exchange as well as the market participants.
We now establish our helping values:

- Alpha per Share
- Absolute Impact Weight
- Lambda & Lambda per Share
- Depth
- Maximum Change allowed
- Round to .50 every change
- Soft Floor Delta for allowing a minimum of below base price
- A Warmup Period in order for the algorithm to get a feeling of the market
- A Lambda Ramp
- Crisis Times, so that it is defined when crisis could be triggered
- Spike Multiplier
- Spike Drop Percentage

## State Variables

These are used to keep track of market behavior, in case we see any irregularities, state changes and therefore the behavior as well.
We have the following fixed variables:

- Event Counter, to keep track of number of events where price changed
- Crisis Triggered, which confirms if crisis was triggered
- Last Row, where we get the last row from the database
- EMA shares and volumes
- Warmup Count, which counts the number of warmup intervals
- Cumulated profit
- Cumulated sold
- Current prices, initialized with base prices

## Algorithm Engine

### Exponential Moving Average

In a regular market, the price of a stock is dependent of how it is valued based on fundamentals (profit, cashflow, assets). Once a stock is on the market, it fluctuates depending on how much investors are willing to bid for it.
In investobar, the rules are slightly different. First we establish the price, based on how much we paid for the product to have it at the bar, ie how much the market values it. But because we don't have market participants who bid, rather they try to catch the cheapest price, we can't have much fluctuation as the market.
So we implemented Exponential Moving Average (EMA) so that the price fluctuates more as if it were in the market.
EMA can be applied on volumes and shares and we did both. The reason we added it on volumes, is to keep track of previous purchases of the same product. EMA on shares, helps with comparing popularity among products, so that they can be correlated and we create a sort of "fair" market.

**Formula**
**EMAₜ = α × Valueₜ + (1 − α) × EMAₜ₋₁**

We check first if we're still in a warmul phase. If we are, then we calculate the EMA for volumes first. If there is no EMA for volumes, means that there is no historical purchase, so we can take the last list of purchases from this session, otherwise we use the formula.
Then we establish the total of last session. If total is greater than zero, means we had purchas last session, therefore we start calculating the EMA for shares.
We first establish the ratio of purchases for each product, then same is in volumes case, if EMA for shares is null, we assign the current ratio, otherwise we use the formula.

### Price Calculation

First we assign the average quantity sold from the last session, if any purchases have been made and we assure that the value is an int.
Then we establish how deep the price will fluctuate based on the average quantity and we use a weight distribution. The weight distribution is to balance the surprises in case of a busy night and to increase prices in case it gets too quiet.
The log of the average quantity is what helps to keep the price steady.

Once we're done, we start changing the lambda values for our EMA going forward.
We calculate lambda once we're out of the warmup period and slowly increasing to maximum capacity.
Once we got the new lambdas, we start calculating the new EMA values.

**Now we start assigning a new price for each drink**
For each drink, we assign a variable for the current price and base price.
Then we assign its ratio and the expected share based on EMA.
To which we have a denominator to establish a certain wiggle room.

We apply the same logic to volumes.

After which, we establish the new prices.
